## Context

`Demo.Web.Api` pulls in Swashbuckle, Serilog and ASP.NET Core, none of which relate to the library. The Swashbuckle 10 upgrade broke the solution build, and because both release workflows build the whole solution, no tag could publish. The API also hid lifetime behaviour behind HTTP requests, and its `Scoped` in-memory user store reset on every request, so a POST followed by a GET returned 404.

## Scope

- Replace `example/Demo.Web.Api` with `example/Demo.ConsoleApp` on the generic host (`Host.CreateApplicationBuilder`), keeping the layered `AddDemoX()` + `AssemblyReference.Assembly` pattern.
- Demonstrate Transient, Scoped and Singleton lifetimes across two scopes by printing instance IDs.
- Run a short user scenario that writes in one scope and reads in another.
- Make the in-memory user store a thread-safe singleton and stop exposing a mutable `HashSet` across layers.
- Use `IClockService` in `UserService` instead of `DateTime.UtcNow`.
- Update `AutoRegister.slnx`, `CLAUDE.md` and the wiki pages that describe the example.

## Acceptance criteria

- [x] `dotnet build AutoRegister.slnx -c Release` succeeds with no warnings.
- [x] `dotnet run --project example/Demo.ConsoleApp` shows the auto-registration log, the lifetime comparison and the user scenario.
- [x] The example has no third-party package references.
- [x] No remaining references to `Demo.Web.Api` in the solution, `CLAUDE.md` or `wiki/`.
